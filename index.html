About the OS:

For now, NicksterOS only has 5 apps (more coming soon) and those 5 apps are: user guide (what you're in right now), chrome, NRterminal, Nick notes (notes app), and App Archives (no apps yet :[). Nick notes is used for writing notes and later a file system will be added to the OS soon. Chrome is exactly what it sounds like, although it uses bing as chrome doesnt work properly, i already made the chrome logo so i decided to keep it also, if you click on a link, it will open that tab in your actual browser (still a bug in progress). NRterminal is used for simple commands and isnt really useful (yet :]). App archives is a app that will let you "download" apps to your desktop. APPS COMING SOON: Settings: can change backround, user name, etc. Snake: simple game to play in the desktop :].
